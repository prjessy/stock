# SESSION 2026-07-02 — 수급관리(투자자 매매동향) 가독성 개편

## 배경 / VOC
사용자: "수급관리 맞는건가? 좀 보기 어렵네.. 도대체 기관·외국인·개인 얼마나 살고 팔았는지? 장중에는 또 이상하게 나오고." → "가독성 있게 해줘, 너무 보기 힘들어."

## 진단 (문제는 3가지, "가독성"은 그중 하나였음)
1. **표시 지표가 틀림** — 순매수를 **수량(주)** 으로만 표시. 사람은 "돈(억원)"으로 생각하는데 `▲1.2만주`가 얼마짜리인지 알 수 없었음.
2. **필요한 데이터 누락** — 순매수(=매수−매도) 하나만 있었고 **매수/매도 원본은 화면에 없었음**. KIS가 주는데도 미사용.
3. **장중 = 버그 아님(안내 부재)** — "장중에 이상하다"는 사실 **실시간 누적치가 정상적으로 변하는 것**. 화면이 이를 설명 안 해 오해 유발.
4. (가독성) 범례·색 설명 부재.

## 핵심 발견 — KIS 필드 단위
`inquire-investor`(TR `FHKST01010900`) 응답은 순매수 수량뿐 아니라 **거래대금**을 함께 준다:
- `*_ntby_tr_pbmn` = 순매수 거래대금, `*_shnu_tr_pbmn` = 매수, `*_seln_tr_pbmn` = 매도
- **단위 = 백만원 → 억원 = ÷100** (검증: 삼성 개인 순매수 6,951,718주×286,000≈1.99조 = 2,022,858백만원)
- `_shnu_`=매수, `_seln_`=매도, `_ntby_`=순매수

## 변경 내용
### 백엔드 `app/datasources/kis_price.py` — `get_investor_flow()`
기존 순매수 수량(주) 필드는 **하위호환 위해 유지**하고 아래 추가 반환:
- 순매수 금액(억원): `frgn_ntby_amt` / `orgn_ntby_amt` / `prsn_ntby_amt` + 5일합 `*_amt_sum`
- 당일 매수/매도 금액(억원): `frgn_buy_amt`/`frgn_sell_amt`/`orgn_*`/`prsn_*`
- 헬퍼 `_amt()`(백만원→억원 ÷100), `_amt_sum()`

### 프론트 `app/web/static/index.html`
- `fmtAmt(n)` 추가 — 억원 포맷(1조=10,000억, 조 단위 표기).
- `renderSupplyTable()`(📊대시보드 탭 `flowSupply`): 셀을 **순매수 금액(억원)** + 5일 누적으로. 범례 추가(▲빨강=순매수(샀다)/▼파랑=순매도(팔았다)). 하단에 `<details>` **"🔍 오늘 얼마나 사고 팔았나"** — 투자자별 샀다/팔았다/순 분해.
- `renderSupplySummary()`(🏠써머리 탭 `sumSupply`): 금액(억원) 중심 + 범례.
- `supplyBadge()`: 장중=`🟡 장중 실시간 잠정치 (마감 후 확정·계속 바뀝니다)`, 마감후=`✅ 당일 마감 확정`.
- 카드 헤더/설명 문구 갱신.
- 색상 규칙(기존): `--up`=빨강(순매수/샀다), `--down`=파랑(순매도/팔았다) — 한국식.
