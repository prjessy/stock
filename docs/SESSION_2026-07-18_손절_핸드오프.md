## As-Is (VPS 라이브 · jessystock.com)

공개 HTML 확인 기준 (2026-07-18):

- **🤖 자동매매 탭** 존재 · 비밀번호 잠금
- 종목 규칙에 **손절가 / 손절% / 매도시각** 포함
- 감시·주문: `AutoTradeWatcher` + `/api/autotrade/config` + KIS `OrderClient`
- 잔고 기준 문구: 「자동 매도(손절)는 이 보유분을 기준으로 동작합니다」
- **🛡️ 손절 전용** 패널·`/api/autosell/*` 문구는 라이브 HTML에 **없음** (전용 모듈 미배포)

### 손절만 쓰는 최소 설정 (권장 사용법)

```text
https://jessystock.com
  → 로그인(오너)
  → 🤖 자동매매 탭 (TRADE_PASSWORD)
  → 종목별: 손절가 또는 손절% 입력
  → 매수%·매도% 비우기 (손절만 쓸 때)
  → 자동매매 전체 ON → 비밀번호 저장·적용
```

### 발동 조건 (자동매매 안 손절)

1. **손절가** — 현재가 ≤ 지정가  
2. **손절%** — 평단 대비 손익률 ≤ 값 (예 −3)  
3. **매도시각** — KST 해당 시각 이후  

공통: 마스터 ON · 한국 장중 · 실제 보유 · 종목·행위당 하루 1회 등 (기존 autotrade 안전장치).

### 탭이 복잡해 보이는 이유

한 탭에 주문테스트·AI판단·잔고·케어·밴드매수매도·손절·분할·발목·체결이 **혼재**.  
기능은 살아 있으나 UX가 섞여 있음 → 사용자가 “이미 있는데 복잡하다”고 느낀 원인.

## To-Be (로컬 PC만 · `Documents/stock`)

삭제됐던 **손절 전용(autosell)** 을 pyc 흔적 + autotrade 패턴으로 복원·연동한 상태.

| 파일 | 역할 |
|------|------|
| `app/trading/autosell_config.py` | `data/autosell_config.json` 저장 |
| `app/trading/autosell_watch.py` | 장중 매도 전용 감시 (매수 없음) |
| `app/web/api.py` | `GET/POST /api/autosell/config` · startup `_autosell.start()` |
| `app/web/static/index.html` | 🤖 탭 안 **🛡️ 손절 전용** 패널 |
| `tests/test_autosell.py` | 설정·트리거 단위 테스트 |

- 설정 키: `stop_price`, `stop_pct`, `sell_time`, `max_qty` + 마스터 `enabled`
- 보안: `_is_owner` + body `password` == `.env TRADE_PASSWORD`
- **VPS 미배포** → jessystock.com 에는 아직 안 보임

### 나중에 배포할 때 (선택)

- 배포 방식: 기존과 동일 **scp + `systemctl restart stock-watchdog`** (git pull 아님). 상세 경로·IP는 로컬 메모리/폴더만.
- 올릴 핵심: 위 표 파일들 (+ 필요 시 `tests/test_autosell.py`)
- ⚠️ 배포 후 **손절 전용 ON** 과 **자동매매 손절 필드** 를 같은 종목에 이중 설정하지 말 것 (중복 매도 위험).  
  전용 쓸 때 → 자동매매 쪽 손절칸 비우기.
