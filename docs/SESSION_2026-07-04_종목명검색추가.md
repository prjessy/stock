# 세션 2026-07-04 — 종목 추가를 「종목명 자동완성」으로 개편 (VOC)

> VOC: "코드를 외울 수가 없다. 종목명으로 추가하게 해달라." → **국내+미국 모두 이름으로 검색·추가** 가능. **VPS 라이브 배포 완료** (scp + restart, git 미경유).

## 사용법
- 대시보드 「＋ 내 종목 추가」 또는 ⚙️설정 → 종목 관리 입력창에 **이름만 입력**:
  - 국내: `삼성전` → 드롭다운(삼성전기/삼성전자/삼성전자우…) → 클릭 즉시 추가
  - 미국: `애플`·`테슬라`(한글 별칭) 또는 `apple`(영문명) → AAPL 등 선택
  - 기존 코드(005930)·티커(AAPL) 입력도 그대로 동작. 이름 정확일치면 Enter만 쳐도 서버가 코드로 해석해 추가.
- 브라우저 캐시 주의: 안 보이면 **Ctrl+Shift+R**.
