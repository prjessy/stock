## 1. 요청 (VOC)
> "매매일지 6월과 7월 같이 볼 수 없네. 그래서 **현황이 먼저** 나오고 **검색** 그리고 **＋ 누르면 입력**하게 바꿔줘.
> 검색은 날짜(7일, 1달, 1년, 사용자 선택, 조건 없음), 종목명."

핵심 문제: 기존 **기록** 탭은 입력폼이 항상 맨 위를 차지하고, 목록은 종류(전체/일반주/공모주) 필터만 있어 **기간 검색이 없었다**. 여러 달을 한 화면에서 훑기 불편.

## 2. 변경 내용 (프론트 단독)
파일: **`app/web/static/index.html`** 한 개만 수정. **서버 API(`app/web/api.py`)·DB 무변경.**

### 기록 뷰(`#jview-record`) 재구성 — 3블록 순서
1. **📊 현황** (`#jrnStatus`) — 검색 조건이 반영된 요약 카드 6개: 거래건수·매수합계·매도합계·실현손익·배당합계·세금합계. 제목 옆(`#jrnStatusRange`)에 현재 적용 범위 라벨 표시(예: `· 최근 1달 · 삼성전자`).
2. **🔎 검색** — 날짜 범위 칩(`#jrnDateFilter`: `all`/`7d`/`1m`/`1y`/`custom`) + 사용자 선택 시 시작·끝 date input(`#jrnCustomRange`, `#jrnCustomStart`/`#jrnCustomEnd`) + 종목명 텍스트(`#jrnNameQuery`) + 종류 필터(`#jrnCatFilter`, 기존 유지).
3. **📒 내 기록 + ＋** — 목록(`#journalList`) 헤더 우측에 **＋ 새 기록** 토글 버튼(`#jrnAddToggle`). 평소 입력폼(`#journalForm`)은 `display:none`, 누르면 펼침(버튼이 `✕ 닫기`로 토글), `취소`(`#jrnFormCancel`)로 접기. 폼 펼치면 종목명 필드 자동 포커스.

### 새 JS (index.html 내 인라인)
- 상태변수 추가: `jrnDateFilter="all"`, `jrnCustomStart`, `jrnCustomEnd`, `jrnNameQuery`.
- `jrnDateBounds()` — 범위칩→`{start,end}` (YYYY-MM-DD). 상대범위는 `new Date()`에서 계산(`toISOString().slice(0,10)`, 기존 코드와 동일 방식).
- `jrnRangeLabel()` — 현황 제목용 사람이 읽는 라벨.
- `filteredJournalEntries()` — **종류 + 날짜범위 + 종목명**을 모두 AND로 적용. 종목명은 `name + symbol` 소문자 부분일치.
- `renderJournalStatus()` — 필터된 항목으로 현황 카드 렌더(리포트 카드 로직 재사용).
- `renderJournalList()` — 맨 앞에서 `renderJournalStatus()` 호출, 목록도 `filteredJournalEntries()` 사용. 빈 목록 문구: 데이터 있으면 "검색 조건에 맞는 기록이 없습니다", 없으면 "위 ＋ 새 기록으로…".
- `bindJournalUI()`에 바인딩 추가: 날짜칩 클릭(→custom이면 커스텀박스 표시), 커스텀 날짜 change, 종목명 input(즉시 재렌더), ＋토글/취소.

### CSS 추가 (`app/web/static/index.html` `<style>`)
`.jrn-search-row`, `.jrn-search-row #jrnNameQuery`, `.jrn-custom-range`(+`label`,`input`). 기존 `.jrn-subtabs`·`.rep-cards`·`.rep-card` 재사용.

### 손대지 않은 것
캘린더 뷰·리포트 뷰·입력폼 필드/제출 로직(`bindJournalForm`)·USD 환율 처리·실현손익 계산 전부 그대로.
